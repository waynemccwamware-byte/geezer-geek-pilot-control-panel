Purpose: How many times each GeezerGeek Pilot app has been opened, most-used first. Reading these numbers doesn't add to them.

An “open” is one page load, including reloads and the author's own testing. Each app's counter started on a different date, so compare with that in mind.

“Visitors” counts distinct internet addresses (not people), and only the Tally counters report it.
